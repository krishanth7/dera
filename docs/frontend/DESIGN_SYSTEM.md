# Design System & Component Library — Phase 7.1

## Visual Direction
Corporate, technical, restrained, high information density. Avoids unnecessary glassmorphism and animations.
- Primary Accent: Technical Indigo / Blue (`hsl(221 83% 53%)`)
- Surfaces: Professional slate neutrals (`hsl(210 20% 98%)` light, `hsl(222 47% 8%)` dark)

## Component Primitives
- `Button`: Primary, secondary, outline, ghost, destructive, with loading spinner.
- `Input`: Accessible form inputs with error states.
- `Card`: Structured container primitives (Header, Title, Description, Content, Footer).
- `Badge`: Status badges (default, secondary, outline, success, warning, destructive).
- `Dialog`: Fully accessible modal dialogs powered by Radix UI.
- `Table`: Technical data table styling with overflow handling.
- `Skeleton`: Content placeholder for asynchronous loading.
- `EmptyState`: Standardized empty view with call-to-action button.
- `ErrorState`: Alert-role error container with recovery retry action.
- `Toast`: Global notification toast viewport with polite ARIA announcements.
