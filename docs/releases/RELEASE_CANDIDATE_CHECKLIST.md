## 1. Overview & Verification Standard

This checklist governs the qualification of prospective **Release Candidates (RC)** prior to maintainer sign-off and publication. Every requirement must be verified with auditable evidence. Unchecked items remain incomplete until substantiated.

---

## 2. Pre-Flight Qualification Verification Table

| Category | Verification Item | Verification Command / Evidence | Status | Verified By |
|---|---|---|:---:|---|
| **Source Revision** | Git commit SHA identified (40-character hex) on default branch | `git rev-parse HEAD` | `[ ]` | — |
| **Version Syntax** | Candidate tag conforms to SemVer 2.0.0 (`vX.Y.Z-rc.N`) | `python scripts/release/validate_version.py --tag "vX.Y.Z-rc.N" --require-candidate` | `[ ]` | — |
| **Workspace Sync** | All 7 version declaration files synchronized | `python scripts/release/validate_version.py --check-consistency --disallow-dev` | `[ ]` | — |
| **Changelog** | `CHANGELOG.md` entry populated with verified additions and fixes | Review `CHANGELOG.md` section `## [X.Y.Z-rc.N]` | `[ ]` | — |
| **Main CI Suite** | Python 3.12 & 3.13 test suites passed with 0 failures | GitHub Actions `DERA CI` run ID | `[ ]` | — |
| **Contracts** | TypeScript compiler check and contract schema parity validated | `npm run build && npx tsc --noEmit` | `[ ]` | — |
| **Database Gate** | SQLite and PostgreSQL 16 read-only integration verified | `python -m unittest tests/integration/test_database_real.py` | `[ ]` | — |
| **Security SAST** | CodeQL scans for Python, TS, and Actions passed with 0 High/Critical | GitHub Actions `CodeQL Advanced Security` | `[ ]` | — |

| **Human Sign-off** | Lead maintainer explicit written publication authorization | Maintainer digital signature or recorded issue sign-off | `[ ]` | — |

## 3. Evidence Collection Protocol

1. **Test Telemetry:** Attach `reports/test-results.xml` and `reports/test-summary.json` generated by `test_reporter.py`.
2. **Artifact Manifest:** Attach generated `dist/manifest.json` and `dist/SHA256SUMS.txt`.
3. **Workflow Run URL:** Link the successful GitHub Actions qualification workflow run.
4. **Sign-off Record:** Document maintainer confirmation in the release preparation PR or tracking issue prior to initiating the publication workflow.
